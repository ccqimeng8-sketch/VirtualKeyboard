# ScreenTouchPad

我的游戏本实在太厚了，不想天天背着去上课。可有些事又得用电脑，我就想着拿 iPad 远控。结果搓玻璃远控电脑的体验实在一言难尽。再买一套蓝牙键鼠吧，带起来麻烦，平时用得也不多。

有一天我忽然意识到，手机就是一块巨大的触控板……

于是有了 ScreenTouchPad。它把安卓手机变成 iPad 的蓝牙键盘和多点触控板，让我用手机控制 iPad，再用 iPad 远控电脑。手机通过经典蓝牙 HID 连接，iPad 上直接用系统蓝牙设置配对。

## 安装和配对

手机需要 Android 9 或更高版本，以及系统提供的蓝牙 HID 设备模式。同一 Android 版本下，蓝牙兼容性仍可能因机型和系统而异。

1. 到 [GitHub Releases](../../releases/latest) 下载 `ScreenTouchPad-0.2.22.apk`，安装后允许「附近的设备」权限。
2. 打开 ScreenTouchPad，点右上角齿轮，进入「配对与连接 → 管理蓝牙连接 → 配对新 iPad」，允许手机在短时间内被发现。
3. 在 iPad 上打开「设置 → 蓝牙」，从设备列表中选择安卓手机，并确认系统提示。手机显示「已连接」后，返回触控板即可操作。
4. 已有配对记录时，可在手机的「管理蓝牙连接」里点「连接」对应的 iPad。

## 操作

手机横屏打开后默认显示触控板。点左上角按钮切换触控板和键盘，点右上角齿轮打开设置。

手指按在触控板上时，手机端会显示淡色圆圈和滑动轨迹。尾端随距离与时间渐隐，抬手后会自动消失。

| 操作 | 效果 |
| --- | --- |
| 单指滑动 | 移动光标 |
| 单指轻点 | 左键，可在「手势设置」开关 |
| 单指轻点后，再按住滑动 | 按住左键拖移 |
| 双指轻点 | 右键，通过 Control＋点按在 iPad 上打开快捷菜单 |
| 双指滑动或捏合 | 传给 iPadOS 处理滚动和缩放 |
| 三指滑动 | 传给 iPadOS 处理系统手势 |

- **灵敏度设置**可分别调节 X、Y 轴和额外加速度。右侧磁铁亮起时，拖动任一滑杆会同步两轴数值。双指、三指的起滑距离可以分别设置，也可以调整多指滑动增益。
- **手势设置**可调整单指移动和双指滚动的反向选项，开关多指手势，并在试滑区检查手机系统是否抢占三指输入。
- **键盘设置**提供完整键盘和精简键盘。精简布局保留数字行、交错排列的字母区和 Command 等修饰键，可通过「符号」键切换字符。

## 防误触与机型验证

受限于手头的设备，防误触设置目前只在 ColorOS 上完成调试和实机验证，测试机是一加 Ace 5 至尊版（PLC110）。其他品牌手机在应用里有设置指引和试滑区，暂未在对应机型上实测。

如果三指滑动触发了截屏或系统助手，可以进入「设置 → 手势设置 → 三指防误触」，按机型查看指引，并在试滑区确认触摸是否仍被系统拦截。系统菜单和应用级防误触开关随系统版本而异。

欢迎提交 PR，补充其他机型的防误触设置路径、适配方案或实机验证结果。提供手机型号、系统版本和复现步骤，可以帮助复测。

## 常见问题

- **连接超时**时，检查手机的蓝牙和「附近的设备」权限，回到配对页重新进入可发现状态。已有配对记录时先尝试重连，只在双方配对记录失效时删除旧记录再配对。
- **指针或手势手感**可结合手机应用里的增益和 iPad 的「设置 → 通用 → 触控板」选项调整。滚动、缩放和系统手势最终由 iPadOS 及目标应用处理。

## 从源码构建

需要 JDK 17、Android SDK Platform 36 和 Android SDK Build-Tools 36.0.0。配置好 Android SDK 路径后，在项目根目录运行 Gradle Wrapper。Windows 使用 `gradlew.bat`，macOS 或 Linux 使用 `./gradlew`。

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

生成的调试安装包在 `app/build/outputs/apk/debug/app-debug.apk`。构建 ColorOS 测试版时，在同一命令中加上 `-PactivityCategory=game`。两个 APK 使用同一包名，适合分别安装测试。

蓝牙 HID 描述符和报告编码位于 `HidReports.java`，蓝牙连接和报告发送位于 `HidConnection.java`。触控板位移和轻点识别分别由 `TrackpadMotion.java` 和 `TapGesture.java` 处理。`tools/` 中的 ColorOS 调试脚本面向已授权的 ADB 测试环境，普通安装使用应用内的防误触指引即可。
